# Text Adventure Game – Object-Oriented C++ Project

A modular text adventure game engine written in modern C++. Players explore a world made of interconnected rooms, collect items, interact with NPCs, and trigger scripted events — all through typed text commands. The project demonstrates object-oriented design, data-driven world loading, and modular systems like saving/loading and event scripting.

## Features

- Full game loop and parser
- Player movement and inventory
- NPC dialogue and interaction
- File-based world definition
- Expandable via new rooms, items, and scripts

## Build

```
make
./textadventure
```
